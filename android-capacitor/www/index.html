Photo preparation checklist

  1. Place each page flat on a plain surface.
  2. Use bright, even lighting; avoid shadows and glare.
  3. Keep the whole page and all margins inside the photo.
  4. Tap to focus; avoid blur and tilted angles.
  5. Upload pages in their correct order and tell the AI how many pages you supplied.
  6. Check every unclear word, number, mark and Arabic tashkīl manually.

How to use AL-AMEEN EXAMFLOW

Before you begin

Prepare one paper for one class and one subject. You do not need to fill every box: only Class / level, Subject and the questions are essential. Other details have defaults or are optional.

  1. Start a paper. Tap Start preparing a paper or New paper. Choose Western Education, Islamiyya or Tahfiz.
  2. Enter the class and subject. Examples: Basic 4, JSS 2, Hifz Level 1; English Language, Mathematics, الْقُرْآنُ الْكَرِيمُ. These two fields are required.
  3. Check the prefilled details. Examination, session, date, duration and maximum marks are suggested defaults. Change only what is different. Teacher name and general instructions are optional.
  4. Paste questions. Tap the bulk area to expand it. Begin each top-level question with a hyphen (-) at the start of a new line. Do not type [ESSAY], [FILL], [SHORT]. The system detects fill-in-the-blank markers, likely objective options, and common Arabic/English question types automatically. Always review the detected type.
  5. Write options. Put each option on its own line. English options can be written as A. / B. / C. / D. or one option per line after a clear multiple-choice question. Arabic options can be أ. / ب. / ج. / د. or one option per line. EXAMFLOW infers likely option groups and applies labels automatically; check the result.
  6. Parse the questions. Tap Parse questions. Open any question panel to edit its text, automatically detected type, marks, direction, options or answer lines. New manual questions are classified as you type unless you choose a type manually. Set answer lines to 0 for the automatic default or enter a specific count. Tap the heading again to collapse it.
  7. Review the A4 preview. It fits the screen width; scroll vertically to inspect the page. Confirm every question, option, section heading, mark, Arabic character and instruction.
  8. Save the paper. Tap Save paper. The system also saves current edits automatically in browser storage when supported. If you refresh or return after switching apps, unfinished work is restored automatically when a valid recovery snapshot is available.
  9. Save the PDF before the next subject. Tap Save PDF to device / Print, select Save as PDF in the print dialog, choose the destination folder when your device offers it, and finish saving. Return to the app and tap I have saved the PDF. Only then will Next Subject unlock.
  10. Prepare another subject. Tap Next Subject. The previous subject remains in Saved papers; the new paper starts separately.
  11. Extract handwritten questions. Open Question Extraction Assistant, copy the master prompt, attach clear photos to an AI assistant, request a faithful transcription, check uncertain text, then paste the hyphen-based output into the bulk composer.
  12. Protect your records. Use Export backup from the paper library regularly. Browser storage can be erased by clearing app/site data, private browsing, or opening the HTML through a temporary file preview. Backups are the safest extra copy.

Frequently asked questions (FAQ)

Will my work save if I close the browser?

EXAMFLOW automatically stores recovery data in browser storage when available. However, browser closure, operating-system memory cleanup, storage restrictions or cleared app data can still cause loss. Save papers and export backups regularly.

Does EXAMFLOW need internet to create papers?

No. The core standalone editor, paper library and local saving work offline when the browser permits local storage. WhatsApp, email and external AI image transcription need internet.

Where are my saved papers stored?

In the browser's local storage on the device and browser profile used to open the file. They are not automatically shared with another browser, phone or computer.

Can EXAMFLOW automatically save PDFs into any phone folder?

No. The browser controls file downloads and asks the user to select or confirm a destination. Use Export backup to create a separate file copy in Downloads or another folder.

Why does WhatsApp not open?

Check that WhatsApp is installed or that the browser can open wa.me links. An internet connection is required. You can also copy the contact number and open WhatsApp manually.

Why is my Arabic text displayed incorrectly?

Check that the text was entered in correct Arabic order, that the question direction is set to Auto or RTL, and that the selected device/browser has an Arabic font. Inspect the printed preview before saving the PDF.

What should I do if an operation fails?

Do not repeatedly delete or import records. Note the page, button and error message, export a backup if possible, then contact Customer Care with those details.
