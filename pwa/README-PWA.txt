AL-AMEEN EXAMFLOW 3.5.6 — PWA

Upload the CONTENTS of this pwa folder to a static HTTPS host. Do not serve over plain
HTTP except localhost. The host must serve index.html, manifest.webmanifest, sw.js,
and icons/ at the same path.

After publishing:
1. Open the HTTPS address in Chrome on Android.
2. Allow the first page load to finish while online.
3. Use Chrome menu > Install app (or Add to Home screen).
4. Launch from the new icon, then test offline after a successful first load.
5. On Windows, open the same HTTPS URL in Chrome/Edge and choose Install app.

PWA storage is separate from the original file:// HTML storage. Export backup from
the existing EXAMFLOW, install the PWA, then import that backup into the PWA.
Do not clear browser data or delete the old file until the imported papers/drafts
have been verified.
